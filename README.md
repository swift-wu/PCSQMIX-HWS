# PCSQMIX-HWS
This repository contains the code for the paper titled "Safe Priority-Aware Cooperative Decision-Making Framework for Unsignalized Intersections via Infrastructure-Assisted Cooperative Learning".

# Requirements and Installation
gym

highway_env

numpy

tensorflow

tf_slim

torch

# Running the Code
Before running the code, you need to create two folders, model and result, to store the model parameters and experimental results respectively.

# Training
To train the model, use the following command:

python main.py
